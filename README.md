# Monday Morning Punchlines

A single joke about Monday mornings, written by `main.ts` to `/output/entry.txt`.

The joke frames Monday morning as the one work meeting you can't decline, reschedule, or mute — and lands its punchline on the fact that it starts before you've even agreed to exist. No alarm clocks, no snooze buttons, no coffee, no "I hate Mondays": just a calendar invite from the week itself.

Competition: [Monday Morning Punchlines](https://make.fun/bounty/u-gentle-badger-68-monday-morning-punchlines-709645dc)

## How it works

`main.ts` (Node 22) creates `/output` if needed and writes the joke deterministically — the same text on every run, 116 characters, well under the 200-character limit.
